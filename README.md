## 🚀 极简快速启动 (Zero-Config 开箱即用)

任何人下载或克隆本代码仓库后，无需配置任何证书或环境，仅需两步即可运行：

```bash
# 1. 安装项目依赖
npm install

# 2. 启动开发服务器 (自动内置动态 HTTPS，支持手机相机)
npm run dev
```

启动后控制台将输出：
- 🖥️ 电脑本地访问：`https://localhost:5173`
- 📱 手机局域网扫码：`https://<你的局域网IP>:5173`

---

## 🔒 手机相机与 HTTPS 说明 (免配证书机制)

为了让手机浏览器（iOS Safari、Android Chrome 等）能够合法调取后置摄像头进行扫码借还，现代浏览器强制要求使用 **HTTPS 协议**。

本项目已通过 Vite 官方标准插件 **`@vitejs/plugin-basic-ssl`** 实现了**全自动自签名证书托管**：
- **无须在仓库中提交敏感的私钥或证书文件**；
- 任何开发者在任何平台（Mac / Windows / Linux）运行 `npm run dev` 时，插件会自动在内存中为当前局域网 IP 签发临时安全证书；
- **手机首次访问时**：浏览器提示“证书无效/不受信任”属正常本地开发现象，只需点击 **「高级 / 显示详细信息」 -> 「继续访问 / 访问此网站」**，即可直接调起手机高清摄像头！

## 📱 核心模块清单

1. **📷 手机相机扫码借还 (`/scan`)**：
   - 自动调用手机后置镜头进行动态扫码，支持激光辅助框、补光灯控制；
   - 支持相册照片识别与手动输入兜底；
   - 扫码识别后一键原子化借出 (Checkout) 或归还 (Checkin)。
2. **🖥️ 管理端科技大屏看板 (`/dashboard`)**：
   - 实验室设备全景指标 KPI；
   - ECharts 资产状态环形图与热门借调排行榜 TOP 5；
   - 实时借还流水动态播报。
3. **📦 共享物资台账大厅 (`/assets`)**：
   - 多分类检索、状态过滤、物理二维码标签 PNG 高清贴纸预览与下载。
4. **📋 个人借调中心 (`/my-rentals`)**：
   - 查看手头在借器材与一键办理归还。
5. **⚙️ 管理员调度与审计台 (`/admin/`)**：
   - 物资入库、状态调度、全生命周期审计日志追踪、成员花名册与注销管理。
